# Plataforma de Ensino Online - Profe Ale

## Objetivo

Criar uma plataforma online profissional para ensino de espanhol para
crianças de 6 a 12 anos. Projeto piloto, mas estruturado para futura
venda.

------------------------------------------------------------------------

## Estrutura do Projeto

### Modelo Inicial

-   Plataforma Web
-   Login individual para cada criança
-   Apenas seção de **Clases**
-   Sem jogos complexos (por enquanto)
-   Estrutura simples e profissional

------------------------------------------------------------------------

## Hospedagem Gratuita

Plataforma utilizada: - InfinityFree (hospedagem gratuita)

Passos: 1. Criar conta 2. Criar Hosting Account 3. Escolher subdomínio
gratuito 4. Aguardar ativação

------------------------------------------------------------------------

## Instalação do WordPress

1.  Acessar "Manage"
2.  Abrir "Softaculous Apps Installer"
3.  Selecionar WordPress
4.  Clicar em "Install Now"
5.  Configurar:
    -   HTTPS (se disponível)
    -   Nome do site
    -   Usuário admin (não usar "admin")
    -   Senha forte
    -   Email válido
6.  Finalizar instalação

Acesso ao painel: seusite.infinityfreeapp.com/wp-admin

------------------------------------------------------------------------

## Configurações Iniciais Importantes

### 1. Configurações Gerais

-   Ajustar nome do site
-   Ajustar fuso horário
-   Salvar

### 2. Links Permanentes

-   Ir em Configurações → Links Permanentes
-   Selecionar "Nome do post"
-   Salvar

------------------------------------------------------------------------

## Tema Profissional

Tema recomendado: - Astra

Passos: 1. Aparência → Temas 2. Adicionar novo 3. Buscar "Astra" 4.
Instalar 5. Ativar

------------------------------------------------------------------------

## Sistema de Cursos (LMS)

Plugin recomendado: - Tutor LMS (versão gratuita)

Passos: 1. Plugins → Adicionar novo 2. Buscar "Tutor LMS" 3. Instalar 4.
Ativar 5. Configurar assistente inicial: - Permitir registro de alunos -
Criar páginas automaticamente - Papel padrão: Student - Ativar conclusão
de aula

------------------------------------------------------------------------

## Estrutura da Plataforma

### Página Inicial

-   Botão Entrar
-   Botão Criar Conta
-   Apresentação da plataforma

### Área do Aluno (após login)

-   Lista de cursos
-   Aulas com:
    -   Vídeo
    -   PDF
    -   Texto explicativo
    -   Botão "Completar aula"
